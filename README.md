# E-Commerce Sales & Customer Analytics

## Project Overview
This project analyzes e-commerce sales data to identify sales trends, profitable categories, regional performance, and business insights.

## Dataset
The dataset contains 30 e-commerce transactions with:
- Order ID
- Order Date
- Customer ID
- Product
- Category
- Region
- Quantity
- Sales
- Profit
- Payment Mode

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- GitHub

## EDA
The analysis includes data inspection, descriptive statistics, missing-value checking, duplicate checking, correlation analysis, outlier detection, category analysis, regional analysis, and monthly sales trends.

## Power BI Dashboard
The dashboard includes:
- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Profit by Category
- Monthly Sales Trend
- Region, Category and Payment Mode slicers

## Key Insights
- Electronics generated the highest sales.
- Pune was the highest-performing region.
- Pune generated the highest profit.
- Electronics generated slightly higher profit than Accessories.
- March recorded the highest monthly sales.
- Overall sales were ₹998,000 and profit was ₹168,000.

## Recommendations
1. Focus marketing efforts on Electronics.
2. Improve Mumbai and low-performing months through targeted promotions.

## Conclusion
This project demonstrates an end-to-end data analytics workflow using Python and Power BI.
